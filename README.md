# HIKE+ V2.52 — randonnée à plusieurs

Correction du flux participant :
- l'hôte choisit la randonnée ;
- les participants reçoivent un message compact et se synchronisent automatiquement ;
- la vue de groupe bascule vers la carte dès la sélection ;
- le départ synchronisé et le compte à rebours sont conservés ;
- le GPX local est résolu depuis le catalogue de chaque appareil lorsque disponible ;
- maximum 6 personnes.
